# NTT DATA + Google Cloud ประกาศแผน 500 AI agents — Forward Deployed Engineering ฝัง engineer เข้า client เพื่อแก้ pilot-to-production deadlock

## TL;DR
- 8 มิ.ย. NTT DATA + Google Cloud ขยาย collaboration จะ co-innovate **500 AI agents** ครอบคลุม banking, insurance, manufacturing, retail + horizontal function (procurement, marketing, software dev)
- NTT DATA จะ certify **5,000 Gemini Enterprise experts ทั่วโลก** สร้าง practice ใหม่ที่ใช้ forward-deployed engineer ฝังเข้า client environment โดยตรง
- ขนาดยังไม่ตัวเลข revenue/cost ที่ public แต่นี่คือ enterprise services partnership ใหญ่ที่สุดที่ตั้งใจ "ออกจาก pilot" — pattern เดียวกับ ServiceNow+Accenture, KPMG+Microsoft ที่ออกในสัปดาห์เดียวกัน

## เกิดอะไรขึ้น

วันที่ 8 มิ.ย. 2026 NTT DATA (system integrator ญี่ปุ่นที่มีพนักงานทั่วโลก ~190,000 คน) ประกาศขยาย collaboration กับ Google Cloud ที่มีอยู่เดิม โดยมี deliverable เป็นตัวเลขครั้งแรก — joint roadmap ที่จะ **co-innovate และ deploy 500 AI agents** ครอบคลุมทั้ง vertical use case (banking, insurance, manufacturing, retail) และ horizontal function (procurement, marketing, cloud migration, software development) ทั้งหมด build บน Gemini Enterprise platform agents เหล่านี้เป็น "reusable building blocks" ที่ client ใหม่ใช้ได้แบบ pre-built ไม่ต้อง build จาก scratch

สิ่งที่ทำให้ deal นี้ต่างจากดีลปกติคือ **forward-deployed engineering (FDE) model** — NTT DATA จะมี "AI-skilled engineers" หลายพันคน + "industry domain experts" ทำงานเป็นทีมร่วมที่ฝัง (embed) เข้าไปใน client environment เลย แทนที่จะส่ง deliverable ผ่าน proposal/scope/phase แบบดั้งเดิม แล้วใช้ Google Cloud's Gemini + Vertex AI tooling ในการพัฒนา agents บนสุด pattern นี้ลอกมาจาก Palantir FDE ที่ใช้กับ government client มาตั้งแต่ปี 2010 — ตอนนี้กลายเป็น standard playbook ของ enterprise AI services

NTT DATA ยังประกาศจะ **certify 5,000 Gemini Enterprise experts ทั่วโลก** ผ่าน training ที่ร่วมกับ Google ทำ — เลข 5,000 ใหญ่กว่าทีม AI specialist ของ NTT DATA ปัจจุบันมาก หมายความว่าต้อง re-skill consultant ที่มีอยู่จำนวนมหาศาล ภายใน 12–18 เดือน (timeframe ที่ press release ไม่ระบุชัด แต่ context ของ "from pilots to production" บอกว่าเร่งด่วน)

ที่น่าสังเกตคือ NTT DATA ไม่ใช่บริษัทเดียวที่ออก deal แบบนี้ในสัปดาห์เดียวกัน — **ServiceNow + Accenture** เปิด FDE program ที่ Knowledge 2026 (พ.ค.) เพื่อ scale agentic AI บน 300+ pre-built AI agent skills, **KPMG + Microsoft** (9 มิ.ย.) deploy Agent 365 + Copilot กับ 276,000 employees ทั่วโลก เป็นสามดีลเสนอเรื่องเดียวกัน — แต่กระจายอยู่กับ vendor model ที่ต่างกัน (Google Gemini, ServiceNow AI Platform, Microsoft Agent 365)

## ทำไมสำคัญ

ตัวเลข 500 agents + 5,000 expert คือการประกาศว่า **เรากำลังจะหลุดจาก "AI pilot purgatory"** — สถานะที่ Gartner รายงานต่อเนื่องว่า 60%+ ของ enterprise AI project ค้างอยู่ที่ POC โดยไม่ไป production การที่ NTT DATA + Google เลือกแก้ปัญหานี้ด้วย FDE คือยอมรับว่า "agent ออกจาก pilot ไม่ได้เพราะ implementation gap ไม่ใช่ technology gap" — และวิธีแก้คือลด distance ระหว่าง engineering กับ client environment ให้เหลือศูนย์

Pattern ที่เห็นจาก 3 ดีลในสัปดาห์เดียวกัน (NTT DATA+Google, ServiceNow+Accenture, KPMG+Microsoft) คือ **enterprise services consolidation รอบใหม่กำลังเกิด** — big-3 cloud (Google, Microsoft, AWS) จับคู่กับ big-4 consultancy/SI (Accenture, KPMG, NTT DATA, Deloitte) เพื่อแบ่งตลาด enterprise AI implementation Game นี้เคยเกิดในยุค ERP (1990s SAP+Accenture, Oracle+IBM Global Services) — ตอนนี้กำลังเกิดอีกครั้งสำหรับ agentic AI ใครไม่ได้คู่ถูก ขายไม่ได้ ลูกค้า Fortune 500 ที่ต้องการลด vendor count จะเลือกแค่ 1–2 stack/partner

500 agents เป็น "modular IP" ที่ NTT DATA จะ resell ได้กับลูกค้าใหม่โดยไม่ต้อง re-build — เป็น margin lever ที่สำคัญ เพราะ SI business มี margin ต่ำ (10–15%) ส่วน agent ที่ pre-built เหมือน software product จะมี margin 40%+ ถ้าทำงานเสร็จก่อนคู่แข่ง NTT DATA จะมี catalog เดียวที่ขายได้ทั่วโลก ในขณะที่คู่แข่งยัง custom build

## มุม OpenBridge

ข่าวนี้คือ **โอกาส mid-market ที่ใหญ่กว่าที่เห็น** — เพราะ NTT DATA, Accenture, KPMG ไปโฟกัส Fortune 500 ทั้งหมด ตลาด mid-market (500–10,000 employees) ที่ต้องการ agent แบบเดียวกันแต่ไม่มีงบจ้าง FDE ทีมเป็น 100 คนยังว่างอยู่ OpenBridge สามารถ position เป็น **"500 agents in a box for mid-market"** — pre-built agent บน integration platform ที่ลูกค้า self-serve ได้ ไม่ต้องมี FDE team ฝังในออฟฟิศ

อีกมุม — **ดู agent catalog ของ NTT DATA + Google เป็น reference ของ "use case จริงที่ลูกค้าซื้อ"** เพราะถ้า system integrator ใหญ่ขนาด NTT DATA ตัดสินใจ build 500 ตัว ทุกตัวที่ลงทุน build แปลว่ามี demand validation แล้ว OpenBridge ควร track ว่าเขาเริ่ม build อะไรก่อน — categoryไหน priority สูงสุด (น่าจะ procurement, billing, customer service) — แล้วใช้ list นั้นเป็น roadmap ของ integration ที่ต้องสร้าง

ยังมีมุม partnership — NTT DATA, KPMG เป็น "big client" ของ Salesforce, SAP, Workday ทั้งหมด ถ้า OpenBridge ตั้งใจเข้าตลาด Asia (ที่ NTT DATA มี client base ลึก) การมี integration ที่ certified กับ NTT DATA implementation framework จะเป็น distribution shortcut — เป็น strategy ที่ Snowflake ใช้กับ Deloitte สมัย IPO ปี 2020
