# OpenAI Codex แตก plugin เป็น vertical — Finance, Banking, Sales ก่อน ตามด้วย Legal/PE/Consulting Codex พุ่ง 5M weekly users (+6x ใน 4 เดือน)

## TL;DR
- 2 มิ.ย. 2026 OpenAI ปล่อย Codex plugins ตัวแรกที่ไม่ใช่งาน coding — public equity investing + investment banking + sales — มี Moody's, S&P, FactSet, LSEG, PitchBook, Hebbia เป็น data partner
- Codex แตะ 5M weekly active users (+6x ตั้งแต่ desktop app launch ก.พ. 2026), knowledge workers คิดเป็น 20% ของ user base และเติบโตเร็วกว่า developer 3 เท่า
- Plugin ต่อไปคือ legal + corporate finance + private equity + marketing strategy + strategy consulting — OpenAI vs Anthropic race เปลี่ยนจาก "model benchmark" เป็น "vertical workflow + proprietary data access"

## เกิดอะไรขึ้น

วันที่ 2 มิ.ย. 2026 OpenAI ประกาศ vertical plugin ชุดแรกสำหรับ Codex agent — ตัวที่ launch พร้อมกันคือ **public equity investing**, **investment banking**, และ **sales** Bloomberg และ Finextra รายงานเป็นเจ้าแรก โดยเน้นว่า "OpenAI กำลังขยาย Codex จาก coding agent เป็น general-purpose work agent" — เป็น move ที่ตรงไปแข่ง Anthropic ในกลุ่ม enterprise knowledge worker โดยตรง

Plugin **public equity investing** ทำงานร่วมกับ data provider 8 เจ้า: Moody's, Daloopa, Datasite, FactSet, LSEG, S&P, PitchBook, Hebbia — สาม use case ที่ OpenAI ยกตรง ๆ คือ (1) review earnings + filings, (2) compare companies + tracking signals, (3) assess investment theses Plugin **investment banking** มี workflow ตรงสำหรับ banker — turn diligence + comparable transactions เป็น pitch material, prepare client-ready documents OpenAI โชว์ว่าสิ่งเหล่านี้ใช้ "trusted data" ไม่ใช่ web scrape — เป็น signal ว่า enterprise customer ต้องการ data lineage ก่อนจะใช้ output

ที่น่าตื่นเต้นกว่า plugin คือ **เลขผู้ใช้** — OpenAI เปิดเผยว่า Codex มี **5 ล้าน weekly active users** เพิ่มขึ้น 6 เท่าจาก desktop app launch ในเดือนกุมภาพันธ์ 2026 (4 เดือน) Developer ยังเป็น user group ใหญ่ที่สุด แต่ **knowledge worker คิดเป็น 20%** และเติบโตเร็วกว่า developer **3 เท่า** ตัวเลขนี้คือ direct response ต่อ Anthropic Claude Code ที่ครองตลาด developer ไปแล้ว — OpenAI เห็นว่า frontier ของ growth ไม่ได้อยู่ที่ developer (saturate กับ Claude Code + Cursor + Windsurf) แต่อยู่ที่ knowledge worker

OpenAI ระบุชัดว่า plugin ตัวต่อไปคือ **corporate finance, private equity investing, marketing strategy, strategy consulting, legal** — Artificial Lawyer รายงานเร็วกว่าตั้งแต่ 18 พ.ค. ว่า OpenAI วางแผน "Codex for Legal" อยู่แล้ว แต่ยังไม่ launch สิ่งที่ Bloomberg ย้ำคือ "OpenAI กำลัง compete กับ Anthropic ในการเซ็น enterprise customer" — ไม่ใช่ research benchmark อีกต่อไป

## ทำไมสำคัญ

นี่คือ **end ของ era "general-purpose chatbot wins all"** — ตลาด AI กำลังแตกเป็น vertical workflow + proprietary data access ไม่ใช่ "ใครมี model เก่งกว่า" Codex with Moody's/S&P/FactSet สำหรับ banker คือ workflow ที่ ChatGPT generic ทำไม่ได้ ไม่ใช่เพราะ model อ่อนกว่า แต่เพราะไม่มี **data integration + UI flow + compliance contract** กับ vendor เหล่านี้ Anthropic จะต้องตอบด้วย similar plugin/integration shortly ไม่งั้นจะเสีย vertical ทั้งหมดให้ OpenAI

ตัวเลข 5M WAU ของ Codex ที่ +6x ใน 4 เดือนเทียบกับ Claude Code (Anthropic ไม่เปิด WAU แต่ ARR breakdown น่าจะใกล้เคียงหรือสูงกว่า) เป็น **proxy war** สำหรับ AI lab — ใครชนะ agent layer จะชนะ enterprise account ทั้งหมด เพราะ agent คือ entry point สู่ workflow และ workflow คือสิ่งที่ enterprise ยอม pay premium ที่ knowledge worker +3x developer growth rate แปลว่า ChatGPT-style consumer-grade UI กำลังจะถูก replace ด้วย agent-style "ฉันจะทำให้" — และ vertical ที่จับ workflow ได้ก่อนจะ lock-in user 3-5 ปี

Pattern ที่ทุก vertical plugin ของ Codex มีร่วมกันคือ **proprietary data partner เป็น first-class citizen** — ไม่ใช่ web search ไม่ใช่ embedding RAG generic แต่เป็น API contract กับ Moody's, S&P, FactSet ที่เปิดข้อมูล structured + version + audit trail ครบ นี่คือ moat ที่ AI lab สร้างเหนือ open-source model — เพราะ open-source model ก็เก่งใกล้เคียงแล้ว แต่ไม่มี vendor relationship เพื่อ source data ที่ enterprise ใช้จริง

## มุม OpenBridge

นี่คือ **เห็นภาพชัด** ที่สุดเรื่องที่ OpenBridge ควรอยู่ตรงไหนในตลาด — Codex vertical plugin model คือ "agent + workflow + data integration เป็น bundle เดียว" ขายให้ enterprise โดยตรง สำหรับ OpenBridge มีสองทางเลือก: (1) build vertical plugin คล้ายๆ Codex บน multi-model platform (ไม่ผูกกับ OpenAI หรือ Anthropic) — เป็น "Codex for Thai/SEA enterprise" หรือ (2) เป็น **integration fabric** ที่ทำให้ enterprise data + tool ของลูกค้า reachable ผ่าน Codex plugin + Claude MCP server พร้อมกัน — เป็น "ของกลาง" ที่ทั้งสองข้างต้อง integrate

ข้อ 2 น่าจะเป็นจุดที่ defensible กว่าในระยะยาว — เพราะ OpenAI กับ Anthropic จะแย่ง customer กันไปอีก 2-3 ปี ทั้งสองจะ partner กับ data vendor + workflow vendor ที่มี enterprise embedded แล้ว OpenBridge ถ้า position เป็น "enterprise data + tool plane ที่ทุก agent ใช้" + เน้น vertical ที่ Codex/Claude ยังไม่ถึง (เช่น SEA banking, Thai retail, regional logistics) จะมี window 12-18 เดือนก่อน Codex จะแตก plugin มาทับ

อีกเรื่องที่ต้องระวัง — Moody's, S&P, FactSet ที่เป็น **data partner ของ Codex** จะมี exclusivity clause หรือไม่? ถ้ามี OpenBridge ต้องคิดเรื่อง **alternative data partner** (Thai/SEA data provider, sector-specific) ที่ Codex/Claude ไม่มี relationship เร็ว ๆ — ก่อนจะถูก lockout จาก enterprise stack
