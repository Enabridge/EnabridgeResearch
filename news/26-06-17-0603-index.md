# Daily Brief — 26-06-17 รอบ 06:03 (Bangkok)

## Theme ของรอบ

**9-12 มิถุนายน 2026 = "the week enterprise AI grew up"** สี่ข่าวรอบนี้ส่งสัญญาณเดียวกันจากสี่มุม: agentic AI ระดับ enterprise ผ่านจุด "ทดลอง / POC" ไปแล้วทั้งฝั่ง supply (Anthropic / Microsoft / Google + NTT) และฝั่ง demand (KPMG / Sierra customer base) — แต่ในรอบเดียวกันก็ปะทุประเด็น vendor concentration risk ที่ frontier AI ถูก treat เหมือน semiconductor ที่รัฐระงับ deployment ได้ภายในไม่กี่ชั่วโมง

**Anthropic Fable 5 / Mythos 5 ดับ 72 ชั่วโมง** — Anthropic ปล่อย state-of-the-art model 9 มิ.ย. → รัฐบาลสหรัฐส่ง export-control directive 12 มิ.ย. 17:21 ET → Anthropic ปิดทั้งสองรุ่นให้ทุกคน เหตุผล: jailbreak ที่บอกให้โมเดล "อ่าน codebase แล้ว fix flaws" → กลายเป็นเครื่องสแกน zero-day อัตโนมัติ "เปิดสาธารณะ" ไม่ใช่ one-way door อีกแล้ว

**KPMG × Microsoft Agent 365 — 276,000 คน 138 ประเทศ** — deployment ที่ใหญ่ที่สุดในประวัติศาสตร์ enterprise AI, Agent 365 ไม่ใช่ chatbot แต่เป็น governance + orchestration layer ที่ KPMG เอามาเสริม Workbench platform ของตัวเอง (บน Azure AI Foundry) แล้วเอาตัวเองเป็น showcase ขายให้ Fortune 500 — "Trusted AI" framework เป็น differentiator

**Sierra $200M ARR ใน 7 ไตรมาส** — Bret Taylor ทวีต Sierra แตะ $200M ARR ($130M → $200M ใน 2 ไตรมาส) ราคา Series E $950M ที่ $15.8B (Tiger + GV ลีด) Voice agent แซง text เป็น primary channel ตั้งแต่ ต.ค. 2025 — proof ว่า usage-based / runtime billing model ของ agent OS work จริง ลูกค้ายอมจ่ายต่อ interaction

**NTT DATA × Google Cloud — 500 agents + 5,000 certified experts** — partnership ตั้ง "Gemini Enterprise practice" เต็มรูป build productized agent ที่ replicate ได้ ไม่ใช่ custom project pattern คือ Google ใช้ SI สาย APAC แซง Microsoft ในตลาดที่ Microsoft ยึดอยู่

Pattern ที่ขมวด — **ตลาด segment เป็น 3 ชั้นชัด**: governance layer (Microsoft Agent 365), runtime layer (Sierra), factory layer (NTT × Google) — และ winner ของแต่ละชั้นเริ่มชัดขึ้น และในชั้นเดียวกัน: **vendor concentration risk เปลี่ยนจาก theory เป็น production incident** — 72 ชั่วโมงของ Fable 5 พิสูจน์ว่า frontier AI ใช้แทน semiconductor — รัฐสั่งดับได้ทุกเมื่อ OpenBridge ที่ position ตัวเองเป็น vendor-neutral integration layer + per-workflow pricing + multi-model abstraction มี window ที่ไม่กว้างนัก แต่ตำแหน่งชัด

## TL;DR สำหรับ Yoh

- **vendor concentration risk เปลี่ยนเป็น production incident แล้ว** — Fable 5 ดับ 72 ชั่วโมงพิสูจน์ว่า "เปิดสาธารณะ" ของ frontier model กลับได้ และไม่มี SLA ครอบคลุม geopolitical event สำหรับ OpenBridge: ชู "vendor-neutral routing + multi-model abstraction" เป็น core value prop ทันที — case study นี้ใช้ใน sales deck ได้ 6-12 เดือนข้างหน้า, เริ่ม pilot model จีน / open-weight ในตัว reference ก่อน

- **ตลาด agentic AI segment เป็น 3 ชั้นชัด** — governance layer (Microsoft Agent 365 / KPMG), runtime layer (Sierra), factory layer (NTT DATA × Google) — ทั้งสามชั้นมีผู้นำ และ pricing model ต่างกัน (seat / per-interaction / per-license) OpenBridge ต้องเลือกชั้นที่ลงไปแข่ง — แนะนำ "interop layer ระหว่างชั้น" (ช่วยให้ Sierra voice agent ส่งงานต่อ workflow ภายในที่ใช้ Azure ได้แบบ first-class) ไม่ใช่แข่งกับ vendor ตรง ๆ

- **Sierra พิสูจน์ usage-based pricing ของ agent ขายได้** — $80x ARR multiple ที่ Series E แปลว่าตลาด TAM ของ agent platform ใหญ่กว่าที่หลายคนคิด OpenBridge ควรเริ่มทดลอง pricing แบบ per workflow-execution หรือ per agent-action คู่ seat-based ภายในไตรมาสนี้ — ถ้ามี milestone จับได้ จังหวะคุย investor ไม่ดีกว่านี้แล้ว

- **Big 4 + SI กำลัง commodify การ deploy ใน APAC ภายใน 12-18 เดือน** — KPMG × Microsoft / NTT DATA × Google จะส่ง proposal Gemini / Copilot bundle ให้ enterprise ไทย / สิงคโปร์ตั้งแต่ Q3 ปีนี้ OpenBridge ต้องตัดสินใจระหว่าง (a) ทางเลือกถูกกว่าสำหรับ SMB / mid-market ที่ไม่จ้าง Big 4 หรือ (b) extension layer บน Microsoft + Google stack ที่ทำสิ่ง Big 4 ไม่ครอบคลุม — ไม่ใช่ทั้งสองพร้อมกัน window สั้น 6-12 เดือนก่อน default lock-in
