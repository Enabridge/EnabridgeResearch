# Daily Brief — 26-06-22 รอบ 06:02 (Bangkok)

## Theme ของรอบ

**15–18 มิ.ย. = "stack consolidation week"** ในสัปดาห์เดียว 4 ข่าวรวมกันส่ง signal ว่า agentic AI ยุค vendor neutral + open protocol กำลังเข้าสู่ phase ที่ hyperscaler + enterprise CRM ผนวก agent stack เข้าตัวเองอย่างจริงจัง — ไม่ใช่แค่ feature แต่เป็น product line หลัก

**Salesforce Agentforce $800M ARR + Summer '26 Multi-Agent GA** — 169% YoY, 29,000 ดีล, 18,500 ลูกค้าใน 124 ประเทศ Benioff เรียก "fastest growing product ever" Atlas Reasoning Engine 3.0 ใช้ agent description routing real-time + รองรับ MCP + A2A protocol — message ชัด: enterprise CRM ที่มี context business จริงกินตลาด standalone agent platform

**AWS Summit NYC** — Swami ขึ้น keynote ในตำแหน่งใหม่ "VP of Agentic AI" เปิด AgentCore Gateway ที่แปล REST API → MCP อัตโนมัติ + Amazon Quick (long-running autonomous agent) + AWS Context (auto knowledge graph) + Continuum security agent + Kiro Mobile + $200B infra commit ใน 39 region — AWS reorg เพิ่ม agentic เป็น business unit ก่อนใครใน hyperscaler ทั้งสามค่าย

**Noam Shazeer ย้ายจาก Google ไป OpenAI** — co-author "Attention Is All You Need" + co-lead Gemini + อดีต Character.AI founder กลับเข้า Google ได้น้อยกว่า 2 ปี Altman บอก "อยากชวนตั้งแต่ OpenAI ก่อตั้ง — ใช้เวลา 10 ปี" ตำแหน่งใหม่: "architecture research lead" focus ที่ blueprint รุ่นถัดไป — pattern ที่ OpenAI สะสมคน "ออกแบบ architecture ใหม่หลัง Transformer" ไม่ใช่ scale Transformer ต่อ

**Convey $38M Series A จาก a16z** — no-code digital teammate สำหรับ ops/finance/sales ที่ไม่ใช่ engineer ลูกค้า NBCUniversal/Samsara/Unity/Faire/ChargePoint, 1M+ ชั่วโมง automate, founder อดีต DoorDash 8 ปี — pendulum swing จาก "agent สำหรับ developer" ไปสู่ "agent สำหรับ operator" ที่ TAM ใหญ่กว่าหลายเท่า

Pattern ที่ขมวด — **agent orchestration commoditize เข้า platform ใหญ่, MCP เป็น default protocol (Salesforce + AWS รองรับ GA ในสัปดาห์เดียว, รวมกับ Anthropic + Microsoft ก่อนหน้า = 4 ใน 5 enterprise platform ใหญ่ที่สุดในโลก), talent war กลายเป็น architecture war (OpenAI เดิมพันว่า gain รอบถัดไปมาจาก architecture ใหม่ ไม่ใช่ compute เพิ่ม)** OpenBridge ต้องตอบ 3 คำถาม: moat ใหม่หลัง MCP กลายเป็น default คืออะไร, connector มี machine-readable description ที่ orchestrator agent อ่านได้หรือยัง, พร้อมรับ traffic แบบ "agent-driven burst" จาก long-running session pattern หรือยัง

## TL;DR สำหรับ Yoh

- **Salesforce $800M ARR + MCP/A2A GA = MCP กลายเป็น default protocol ของ enterprise agent อย่างเป็นทางการ** — รวม Anthropic + AWS + Microsoft + Salesforce = 4 ใน 5 platform ใหญ่ที่สุดในโลก สำหรับ OpenBridge: position ต้องเปลี่ยนจาก "protocol translation" ไปสู่ "MCP server registry + governance ข้าม vendor + cross-cloud" — และทุก connector ของเราต้องมี machine-readable description ที่ orchestrator agent (Atlas 3.0, Claude, Bedrock) อ่านได้ มิฉะนั้นถูกเรียกผิดหรือไม่ถูกเรียกเลย

- **AWS reorg "VP of Agentic AI" + AgentCore Gateway = hyperscaler กำลัง absorb agent stack** — เมื่อ AgentCore แปล REST → MCP อัตโนมัติ คำถาม "ทำไมต้องใช้ OpenBridge" ต้องตอบใหม่ คำตอบไม่ใช่ translation แต่เป็น multi-cloud governance + connector ที่ออกแบบสำหรับ long-running session (Amazon Quick pattern) ไม่ใช่ stateless call แบบเดิม — AWS Context ที่สร้าง knowledge graph อัตโนมัติเป็น blueprint ที่ OpenBridge ควร study แล้ว build cross-vendor version

- **Shazeer → OpenAI = talent war กลายเป็น architecture war** — OpenAI เดิมพันว่า gain รอบถัดไปมาจาก architecture ใหม่ ไม่ใช่ compute ถ้าถูก inference cost จะลดเร็วกว่า planning ตอนนี้, gross margin ของ product ที่พึ่ง LLM call เปลี่ยน, GPU pricing ความสำคัญน้อยลง สำหรับ OpenBridge: pricing model ต้อง stress-test scenario "GPT-6 ราคา 1/10 ของ GPT-5 ที่ทำงาน equivalent quality" และ adjacent insight จาก Character.AI ของ Shazeer — agent ที่ลูกค้า B2B ใช้ก็ต้องมี retention loop ที่ดี ไม่ใช่แค่ technical correctness

- **Convey $38M = ตลาด no-code agent สำหรับ non-developer เริ่ม validate แล้ว** — a16z เลือก signal ว่า pendulum swing ไปทาง ops/finance/sales ที่ TAM ใหญ่กว่า, Zapier + Make + n8n เปิด beta "natural language to workflow" แล้ว สำหรับ OpenBridge: นี่คือ direct competitor ที่ใกล้สุดในรอบ ทีม product ต้อง decompose UX + onboarding + pricing ของ Convey ทันที, "natural language to workflow" จะเป็น UX expected default ลูกค้าคาดหวังเร็วกว่า roadmap ของเรา — ต้องตอบให้ได้ว่าไตรมาสไหน ship
