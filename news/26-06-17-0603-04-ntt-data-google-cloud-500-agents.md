# NTT DATA + Google Cloud จับมือสร้าง "AI agent factory" — 500 agent + 5,000 expert คือ playbook ของ SI ในยุค Gemini Enterprise

## TL;DR
- 8 มิ.ย. 2026 NTT DATA ขยาย partnership กับ Google Cloud — สัญญา deploy "up to 500 AI agents" บน Gemini Enterprise platform ครอบ banking / insurance / manufacturing / retail
- ลงทุนสร้าง Gemini Enterprise practice กับเป้า 5,000 certified expert ทั่วโลก พร้อม joint roadmap, technical enablement, go-to-market investment
- Pattern เดียวกับ Accenture × Microsoft / Wipro × OpenAI / TCS × ServiceNow ปีที่แล้ว — แต่ครั้งนี้ Google เลือก SI สาย APAC ที่ใหญ่ที่สุด เพื่อรุกตลาดที่ Microsoft ยึดอยู่

## เกิดอะไรขึ้น

8 มิ.ย. 2026 ที่งาน Google Cloud Next NTT DATA — system integrator ที่ใหญ่ที่สุดในญี่ปุ่นและหนึ่งใน top 10 ของโลก — ประกาศ "Gemini Enterprise practice" แบบเต็มรูปแบบกับ Google Cloud มีสามองค์ประกอบหลัก หนึ่ง: joint roadmap สร้าง "up to 500 AI agents" ครอบ horizontal use case (software dev, procurement, finance, cloud migration) และ vertical (banking, insurance, manufacturing, retail) — เป็น reusable building block ที่ลูกค้า enterprise เอาไป deploy ต่อได้ทันที สอง: training certification — เป้า 5,000 Gemini Enterprise certified expert ทั่วโลก สาม: go-to-market — coordinated investment, joint business planning, managed service offering

ดีลนี้ขนาดเล็กกว่า KPMG × Microsoft ในเชิง headcount (NTT DATA มี ~190,000 พนักงาน vs 276,000 ของ KPMG) แต่ scope ต่างกัน — KPMG คือ professional services firm ที่ใช้ Agent 365 ภายในและเป็น showcase ขายต่อ ส่วน NTT DATA คือ pure SI ที่ลงทุนสร้าง productized agent ที่ standardize ให้ติดตั้งซ้ำกับลูกค้าได้เป็นพัน — "agent as deliverable" ไม่ใช่ "agent as service"

Google Cloud ก็เลือก NTT DATA ด้วยเหตุผลที่ตรงไปตรงมา: APAC คือตลาดที่ Microsoft ทิ้งห่างสุด ส่วน NTT DATA มี delivery footprint ในญี่ปุ่น เกาหลี เอเชียตะวันออกเฉียงใต้ และอเมริกาเหนือ — บวก Google AI ที่ลูกค้ายังคุ้นน้อยกว่า Azure OpenAI การมี SI ที่ลงทุน train 5,000 คนเข้าโครงการนี้คือทางที่ดีที่สุดเพื่อแซง

## ทำไมสำคัญ

มีสองภาพปะทะกันในรอบสัปดาห์เดียว: KPMG × Microsoft ขายให้ enterprise ที่ต้องการ Big 4 framework + governance / NTT DATA × Google ขายให้ enterprise ที่ต้องการ engineering scale + commodity agent ทั้งคู่กำลังบอก buyer คนเดียวกัน ("CIO ของ Fortune 1000") ว่า "เลือก stack เราตอนนี้ ก่อนที่ migration cost จะแพงเกินกลับ"

จุดที่ underrated: ตัวเลข "500 agents" ทำให้เห็นว่า Google + NTT DATA มอง agent เป็น productized asset ที่ replicate ได้ ไม่ใช่ custom project ที่ build ใหม่ทุกครั้ง ถ้า playbook นี้ work เศรษฐศาสตร์ของ AI consulting จะเปลี่ยน — margin จาก labor-intensive integration → margin จาก license + maintenance ของ pre-built agent (เหมือน Accenture ขาย SAP module เดิมที่ build เสร็จแล้ว) Sierra ขาย agent บน runtime / NTT DATA ขาย agent บน license / Microsoft ขาย governance + Copilot — ตลาดกำลัง segment เป็นชั้น และ winner ของแต่ละชั้นชัดขึ้น

สำหรับ APAC โดยเฉพาะ — ตลาดที่ทุกเจ้าทั้ง US มอง — การจับมือ NTT DATA หมายความว่า Google จริงจัง เพราะ NTT มี relationship กับ government / banking / telco ในญี่ปุ่น เกาหลี ไต้หวัน ที่ Microsoft กับ AWS เจาะยาก ไทยที่ NTT DATA มีออฟฟิศใหญ่อยู่แล้ว จะเริ่มเห็น proposal Gemini Enterprise + agent factory bundle ตั้งแต่ Q3 ปีนี้

## มุม OpenBridge

ไม่ direct เกี่ยว — OpenBridge ไม่ใช่ SI — แต่มี implication สำคัญต่อ go-to-market

หนึ่ง: ในไทย NTT DATA เป็น competitor / partner ที่หลีกไม่ได้ ถ้า OpenBridge มี integration ที่ทำงานกับ Gemini Enterprise + Vertex AI ดีเป็นพิเศษ NTT DATA สามารถเป็น channel ที่พาเราเข้าลูกค้า banking / insurance ขนาดใหญ่ — ขั้นต่ำเริ่มคุยกับ Google Cloud Thailand เรื่อง partner ecosystem ตอนนี้

สอง: "agent factory" model หมายความว่าลูกค้าจะมี agent หลายตัวมาจาก vendor หลายเจ้าพร้อมกัน (Google built + Microsoft built + own custom) ภายใน 12-18 เดือนข้างหน้า ปัญหา integration และ orchestration ระหว่าง agent ข้าม stack จะใหญ่ขึ้นทันที — OpenBridge ที่ปูทาง A2A protocol และ MCP connector ไว้ดี ๆ จะได้ tailwind จากสิ่งที่ SI สร้าง ไม่ต้องแข่งกับเขาตรง ๆ

สาม: 5,000 certified expert เป็นจำนวนคนที่ใหญ่มาก — หมายถึงตลาด labor สำหรับ "Gemini Enterprise developer" จะร้อนขึ้นเร็ว OpenBridge ที่จ้าง dev ที่เคยสัมผัส Gemini stack จะมี edge ด้าน hiring ถ้าเริ่ม sponsor training / hackathon ในไทยตอนนี้
