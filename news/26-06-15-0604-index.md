## TL;DR สำหรับ Yoh

- **Distribution > Technology ในยุค enterprise AI** — OpenAI ไม่ใช่ model ที่ดีที่สุด (Fable 5 ตอนนี้นำ SWE-Bench Pro ที่ 11 percentage points) แต่การมี procurement unlock ผ่าน Oracle Universal Credits = win ที่ใหญ่กว่า benchmark สำหรับ BFSI/Gov ที่ใช้ Oracle 10–30 ปี Pattern เดียวกันที่ Anthropic ทำกับ TCS (50,000 associates) และ Google ทำกับ NTT DATA (500 agents catalog) — frontier lab ทุกรายเห็นตรงกันว่า self-serve API + subscription scale ไม่พอสำหรับ Fortune 500 ต้องผ่าน channel ที่อยู่ในระบบลูกค้าอยู่แล้ว

- **Catalog approach กำลังกลายเป็น procurement metric ใหม่** — Salesforce Agentforce 100+ pre-built agents, ServiceNow 300+, NTT DATA targeting 500 บน Gemini ลูกค้าจะถามว่า "vendor X มี catalog ของ agent กี่ตัวที่ pre-built สำหรับ vertical ของฉัน" แทน "model ของ vendor X ทำอะไรได้บ้าง" สำหรับ OpenBridge: ห้าม position ตัวเองเป็น "raw connector marketplace" — ต้อง bundle ใน vertical-specific agent template ที่ขายตรง procurement ได้

- **Fable 5 + Mythos split = business model innovation, ไม่ใช่ safety theater** — Anthropic เปิด Fable 5 ราคา 2x Opus 4.8 แต่ลูกค้าจ่ายเฉพาะ query ที่ผ่าน safeguard (95% session) 5% ที่ flag จะ route ไปยัง Opus 4.8 ฟรี — pattern "tiered safeguard pricing" ที่ scale ได้ พร้อม ExploitBench 78% ที่ทำให้ Mythos ต้องอยู่ใน controlled distribution (Project Glasswing) Anthropic กำลังเป็น vendor offensive security tool ระดับ frontier — market ใหม่ที่ก่อนหน้านี้ split ระหว่าง Mandiant/Cobalt Strike

- **Window 6–12 เดือนของ OpenBridge ก่อน SI/cloud build catalog ของตัวเองที่ครอบจักรวาล** — NTT DATA + Google มี "joint roadmap" 500 agents ที่ NTT DATA เป็น co-product owner ไม่ใช่ customer; TCS-Anthropic ตั้ง dedicated BU ที่จะ build connector ของตัวเอง; OpenAI-Oracle เปิดทาง Oracle ขยาย OCI AI portfolio OpenBridge ต้อง position ในฐานะ "infrastructure ที่ SI/cloud ใช้ใต้ board" + "available บน 2–3 cloud marketplace ที่ enterprise ใช้ procurement contract เดียวกันได้" — ไม่ใช่ alternative ที่ขาย direct ลูกค้า; ทางออกรอด: vertical-specific agent template + neutral connector + observability ที่ทุก SI deploy ผ่านได้
