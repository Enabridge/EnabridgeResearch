# Cognition ระดมทุน $1B มูลค่า $26B — Devin เขียนโค้ด 90% ของบริษัทเอง รายได้พุ่ง 13 เท่าใน 12 เดือน

## TL;DR
- Cognition AI ปิดรอบ $1B ที่มูลค่า $26B — เพิ่มขึ้นกว่าเท่าตัวจาก $10.2B เมื่อ 9 เดือนก่อน
- รายได้ annualized เพิ่มจาก $37M เป็น $492M ภายใน 12 เดือน (13x) ลูกค้า: Goldman Sachs, Mercedes-Benz, NASA, Citi, กองทัพสหรัฐ
- Devin เขียนโค้ดของ Cognition เองจาก 13% (ธ.ค. 2025) เป็น 89% (พ.ค. 2026) — AI coding agent ที่ "กินอาหารตัวเอง" อย่างแท้จริง

## เกิดอะไรขึ้น

วันที่ 27 พ.ค. 2026 Cognition AI ประกาศปิดรอบระดมทุนใหม่มูลค่ากว่า $1 billion ที่ valuation $26 billion — เพิ่มขึ้นกว่าเท่าตัวจากรอบเดือนกันยายน 2025 ที่ $10.2 billion ซึ่งตอนนั้นก็ถือว่าสูงลิ่วแล้ว รอบนี้ co-lead โดย Lux Capital, General Catalyst และ 8VC พร้อมด้วย Ribbit Capital, Atreides Management และ Founders Fund ของ Peter Thiel

ตัวเลขที่ทำให้นักลงทุนกล้าจ่ายราคานี้คือ revenue trajectory ที่ไม่เคยเห็นในบริษัท AI มาก่อน — annualized revenue run rate พุ่งจาก $37 million ในพฤษภาคม 2025 เป็น $492 million ในวันนี้ เพิ่มขึ้น 13 เท่าใน 12 เดือน enterprise usage โตเดือนละ 50% ติดต่อกัน 6 เดือน Cognition ตั้งเป้าจะข้าม $1 billion ARR ภายในปีนี้

ลูกค้าไม่ใช่ startup ทดลองเล่น — Goldman Sachs, Mercedes-Benz, NASA, Citi, Santander และหน่วยงานหลายส่วนของรัฐบาลสหรัฐรวมถึงกองทัพ ล้วนใช้ Devin ใน production สิ่งที่น่าสนใจที่สุดอาจไม่ใช่ตัวเลขลูกค้า แต่คือ Cognition ใช้ Devin เขียนโค้ดของตัวเองจาก 13% ในเดือนธันวาคม 2025 เป็น 89% ในเดือนพฤษภาคม 2026 — dogfooding ระดับที่ไม่เคยเห็นในวงการ AI agent มาก่อน

ในบริบทที่กว้างขึ้น ตลาด AI coding agent กำลังร้อนแรง — สัปดาห์เดียวกัน Simon Willison เขียนว่า Anthropic (Claude Code/Cowork) และ OpenAI (Codex) ต่าง "found product-market fit" กับ coding agent products และ Q1 2026 venture funding ทั่วโลกทำลายสถิติที่ $300B

## ทำไมสำคัญ

ตัวเลข $492M ARR ของ Cognition ทำให้ AI coding agent กลายเป็น "category ที่พิสูจน์แล้ว" ไม่ใช่ "category ที่น่าสนใจ" อีกต่อไป ถ้า Devin ข้าม $1B ARR จริงภายในปีนี้ มันจะเป็นหนึ่งใน SaaS ที่โตเร็วที่สุดในประวัติศาสตร์ — ทำลายสถิติที่ Slack, Zoom และ ChatGPT เคยสร้างไว้

แต่สิ่งที่น่าจับตายิ่งกว่าตัวเลขรายได้คือ "89% of code written by Devin" — นี่คือ proof point ที่แข็งแกร่งที่สุดว่า AI coding agent ทำงานจริงในระดับ production ถ้าบริษัทที่สร้าง AI เชื่อมั่นพอที่จะให้ AI เขียนโค้ดของตัวเอง 9 ใน 10 บรรทัด นั่นเป็น signal ที่ enterprise อื่น ๆ ไม่ควรมองข้าม อย่างไรก็ตาม มีเสียงวิจารณ์เรื่อง reliability — Whalesbook ตั้งข้อสังเกตว่า valuation ที่พุ่งท่ามกลาง "reliability fears" ยังคงเป็นความเสี่ยงที่ต้องติดตาม

pattern ที่ชัดขึ้นเรื่อย ๆ คือ "AI agent ที่ทำงานจริง = revenue จริง" — Cognition ไม่ได้ขาย API หรือ foundation model แต่ขาย "agent ที่ทำงานแทนคน" และลูกค้ายอมจ่ายในระดับที่ทำให้บริษัทอายุ 2 ปีมีรายได้เกือบครึ่งพันล้านดอลลาร์

## มุม OpenBridge

สำหรับ OpenBridge สิ่งที่เห็นชัดคือ **coding agent เป็น proof of concept ว่า vertical agent ทำเงินได้** — ถ้า Devin ทำ $492M จากแค่ "เขียนโค้ด" agent ที่ทำงาน integration, workflow orchestration หรือ data pipeline ก็มีโอกาสสร้าง revenue ในระดับเดียวกัน

อีกมุมที่น่าสนใจ — enterprise ที่ใช้ Devin ต้องการ integration layer ที่เชื่อม Devin กับระบบอื่น ๆ เช่น CI/CD, project management, code review tools — นี่คือ use case ตรง ๆ ของ OpenBridge ในฐานะ MCP-based orchestration layer ที่เชื่อม agent กับ enterprise toolchain
