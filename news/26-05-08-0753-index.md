# Daily Brief — 26-05-08 รอบ 07:53 (Bangkok)

## Theme ของรอบ

**5–7 พ.ค. 2026 คือสัปดาห์ที่ตลาด agentic AI ตอกย้ำเรื่องเดียว — "delivery gap" คือสมรภูมิจริงของปี 2026** ไม่ใช่ benchmark, ไม่ใช่ funding round, ไม่ใช่ valuation. ที่ ServiceNow Knowledge 2026 ใน Las Vegas ที่จัด 5–7 พ.ค. มีของใหม่ออกมา 4 ชิ้นใหญ่ที่อ่านรวมกันแล้วชัด — และข่าว AMD MI350P PCIe ในวันสุดท้าย (7 พ.ค.) เติมชั้นล่างของ stack ให้ครบ

ชั้นบนสุด — Forward Deployed Engineer (FDE) — กลายเป็น "hottest job in tech" ตามคำของ Andreessen Horowitz เอง job posting โต 800% ใน 9 เดือน, comp เฉลี่ย $238k (Staff $630k+), Salesforce commit hire 1,000 คน, EY launch FDE practice, OpenAI/Anthropic/Palantir/Databricks/Cohere ทุกรายมี dedicated function วันที่ 6 พ.ค. ServiceNow + Accenture เปิด **Forward Deployed Engineering Program** ร่วม — purpose-built pod ที่ 2 FDE team รวมกัน นั่งใน customer environment ขายเป็น outcome-based — Accenture quote ตัวเลขของตัวเอง 32% ของผู้นำเห็น sustained AI impact = "delivery gap" ไม่ใช่ technology gap

ชั้นที่สอง — runtime + governance — ServiceNow ออก **Action Fabric** เป็น MCP Server ที่เปิด GA แถมในทุก Now Assist + AI Native SKU ให้ agent ใด ๆ (Claude, Copilot, Gemini, custom) เรียก system of action ของ ServiceNow ได้ ทุก call ผ่าน AI Control Tower — Anthropic เป็น launch partner ผ่าน Claude Cowork; ตัด proprietary lock-in ทิ้ง เก็บ rent ที่ governance plane วันเดียวกัน Microsoft Agent 365 GA + Novaworks ส่ง Core HR บน MCP — สามค่ายใหญ่ออก MCP-native ใน 24 ชั่วโมง MCP กลายเป็น "OAuth ของ AI era" อย่างเป็นทางการ

ชั้นที่สาม — desktop endpoint + benchmark — NVIDIA + ServiceNow ปล่อย **Project Arc** (long-running autonomous desktop agent บน NVIDIA OpenShell sandboxed runtime) + **NOWAI-Bench** (open benchmark, EnterpriseOps-Gym task) ที่ Nemotron 3 Super ของ NVIDIA คว้า #1 — open-source model นำ Claude Opus 4.7 / GPT-5.5 / Gemini 2.5 Pro ในงาน enterprise agent specifically — signal สำคัญที่ frontier proprietary advantage เริ่มหายในงาน vertical

ชั้นล่างสุด — hardware — AMD ปล่อย **Instinct MI350P PCIe** วันที่ 7 พ.ค. — 144GB HBM3E, FP16/FP8 เร็วกว่า H200 NVL 40%, drop-in กับ server เดิม, 8 card per node = 200B–2T parameter aggregated capacity; PCIe Instinct ตัวแรกตั้งแต่ MI210 ปี 2022 = AMD กลับมาขาย Tier 2 enterprise ที่อยากรัน LLM on-prem แต่งบไม่ถึง HGX rack — ตอบโจทย์ Q3–Q4 2026 ที่ regulated enterprise (banking/telco/public) ลงทุน on-prem cluster เล็ก ๆ

Pattern หลักที่ทั้ง 4 เรื่องชี้ตรงกัน: **value capture ของ agentic AI ปี 2026 ย้ายจาก model layer + platform layer → ลงไปที่ delivery layer (FDE) + governance layer (Control Tower / Action Fabric) + sandboxed runtime (OpenShell) + Tier-2 inference hardware ที่ลูกค้าซื้อเอง** — pure-play model lab + horizontal SaaS agent จะถูกบีบ; integrator + governance vendor + hardware vendor ที่ตอบ on-prem จะขยายตัวเร็วใน 12 เดือนข้างหน้า
