# Anthropic กำลังจะแซง OpenAI — $900B valuation จะทำให้ Claude maker เป็น AI startup ที่แพงที่สุดในโลก

## TL;DR
- Anthropic กำลังปิด funding round $30B+ ที่ valuation เกิน $900B — ถ้าสำเร็จจะแซง OpenAI เป็น AI startup ที่มูลค่าสูงที่สุด
- ARR พุ่งจาก $87M (ม.ค. 2024) → $30B (เม.ย. 2026) = โตขึ้น 80 เท่าภายใน 2 ปี โดย Claude Code เป็น growth engine หลัก
- IPO อาจเร็วสุดตุลาคม 2026 — Goldman Sachs, JPMorgan, Morgan Stanley เริ่มพูดคุยแล้ว

## เกิดอะไรขึ้น

Bloomberg รายงานเมื่อ 12 พ.ค. ว่า Anthropic กำลังเจรจา raise $30B ที่ valuation เกิน $900B — ก่อนนับเงินลงทุนใหม่ ตัวเลขนี้ถ้าปิดสำเร็จจะทำให้ Anthropic แซง OpenAI ขึ้นเป็น AI startup ที่แพงที่สุดในโลก Sequoia Capital, Dragoneer, Altimeter Capital และ Greenoaks Capital Partners คาดว่าจะ co-lead ด้วยบริษัทละประมาณ $2B โดยมี Founders Fund ของ Peter Thiel และ General Catalyst ร่วมด้วย

ความเร็วของ valuation escalation น่าตกใจแม้แต่สำหรับ AI: $61.5B (มี.ค. 2025) → $183B Series F (ก.ย. 2025) → $380B Series G (ก.พ. 2026) → $900B+ (พ.ค. 2026) — 15 เท่าในเวลา 14 เดือน สิ่งที่ขับเคลื่อน valuation คือรายได้จริง ไม่ใช่แค่ hype — CEO Dario Amodei เปิดเผยว่า ARR โตจาก $9B ปลายปี 2025 ไป $14B (ก.พ.), $19B (มี.ค.), แล้ว $30B (เม.ย. 2026) ซึ่งหมายความว่า Anthropic เพิ่มรายได้ $21B ภายใน 4 เดือนแรกของปี 2026

Growth engine หลักที่ Amodei ชี้ไปคือ Claude Code — CLI tool ที่เปลี่ยน Claude จาก chatbot เป็น autonomous coding agent โดยตรง ซึ่งสะท้อนใน enterprise adoption ที่ระเบิดตัว Claude Code กลายเป็น category-defining product ที่ developer จ่ายเงินจริงทุกเดือน ไม่ใช่แค่ trial แล้วหาย

ฝั่ง IPO — Bloomberg รายงานว่า Goldman Sachs, JPMorgan และ Morgan Stanley เริ่มพูดคุยกับ Anthropic แล้ว โดย timeline เร็วสุดคือตุลาคม 2026 ถ้า IPO ที่ $900B+ เกิดขึ้นจริง จะเป็น listing ที่ใหญ่ที่สุดในประวัติศาสตร์ tech — ใหญ่กว่า Arm ที่ $54B IPO เมื่อ 2023 หลายเท่า

## ทำไมสำคัญ

ตัวเลข $900B ไม่ใช่แค่ milestone ของ Anthropic แต่เป็น signal ว่า AI race กำลังเข้าสู่ phase ใหม่ — "revenue-driven valuation" แทนที่ "potential-driven speculation" Anthropic ที่ ARR $30B แซง OpenAI ที่ $24B ได้ ทั้งที่เปิดตัวทีหลังและมี brand awareness น้อยกว่ามาก เป็นหลักฐานว่า product-market fit ของ agentic AI tools (โดยเฉพาะ coding agents) แข็งแกร่งกว่า chatbot model อย่างที่คนคิด

อีกประเด็นคือ cap table — Google เคย commit $10B ที่ $350B และอาจเพิ่มอีก $30B ถ้า Anthropic ถึง technical milestones บางอย่าง หมายความว่า Google กำลัง hedge bet ระหว่าง Gemini (in-house) กับ Claude (investment) ในขณะที่แข่งกันโดยตรงในตลาด developer tools สถานการณ์แบบนี้ไม่เคยเกิดขึ้นใน tech industry มาก่อนที่ระดับ $900B

## มุม OpenBridge

สำหรับ OpenBridge สิ่งที่ต้องจับตาไม่ใช่ตัวเลข valuation แต่คือ implication ว่า "Claude Code + agentic workflow = revenue machine ที่พิสูจน์แล้ว" ถ้า Anthropic ที่ขาย AI agent ตรง ๆ ยังโตแบบนี้ บริษัทที่ขาย integration layer ให้ agent เหล่านั้นเชื่อมต่อกับ enterprise tools ก็ควรจะมี market ที่ใหญ่ตามไปด้วย — position ของ "MCP-native integration backbone" ที่คุยกันรอบก่อนยิ่งมี urgency เพราะ Anthropic กำลังจะเป็น public company ที่ต้องเปิด ecosystem ให้ partner เข้ามามากขึ้น

อีกมุมคือ competitive landscape — ถ้า Anthropic IPO ที่ $900B+ จะมี capital มหาศาลที่สามารถ build integration layer ของตัวเอง (เหมือน Salesforce ที่ซื้อ MuleSoft) OpenBridge ต้องสร้าง defensibility ด้วย multi-vendor strategy ไม่ผูกกับ Claude อย่างเดียว
