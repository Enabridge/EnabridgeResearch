# Daily Brief — 26-05-23 รอบ 06:10 (Bangkok)

## Theme ของรอบ

**สัปดาห์ 19-22 พ.ค. 2026 = "Infrastructure ของ agentic AI โตเร็วกว่าทุกคนคาด"**. 4 ข่าวรอบนี้ประกอบกันเป็น mental model ของ stack agentic AI ที่กำลัง mature ขึ้น 3 ชั้นพร้อมกัน — protocol layer (MCP), hardware/device layer (Hark + Nvidia GB200), และ developer/end-user layer (Antigravity + Codex deployment)

**MCP 2026-07-28 release candidate** (21 พ.ค.) เป็น signal ใหญ่ที่สุดของรอบ — ไม่ใช่ feature ใหม่หวือหวา แต่เป็นการปรับโครงสร้าง protocol แบบ structural ที่ใหญ่ที่สุดตั้งแต่เปิดตัว ตัด session state ออกจาก core spec ทำให้ MCP server วิ่งหลัง round-robin load balancer ได้ Tasks กับ MCP Apps ที่เคยอยู่ใน core ย้ายไป Extensions framework + OAuth 2.1 alignment เข้ามาแทน custom auth นี่คือ protocol ที่กำลัง mature จาก "AI dev tool" เป็น "enterprise infrastructure" — ของที่ ops team รับได้ และ Anthropic ให้ 10 สัปดาห์ window ก่อน publish ตัวจริง 28 ก.ค.

**Hark $700M / $6B** (21 พ.ค.) คือ proof point ของ AI-native hardware funding boom — Brett Adcock (ผู้ก่อตั้ง Figure + Archer) เปิดบริษัทใหม่ตัวที่สี่ ภายใน 6 เดือนปิด Series A ใหญ่สุดในประวัติศาสตร์ AI hardware Cap table แปลกที่สุด — **Nvidia, AMD Ventures, Intel Capital, Qualcomm Ventures** ลงเงินด้วยกันในรอบเดียว (ปกติคู่แข่งกันแบบนี้ไม่เคย co-invest) + Salesforce Ventures มาด้วย Hark ยังลึกลับ — "personal AI platform" ที่ทำ foundation model + software + hardware + interface ของตัวเอง ไม่เลือก stack เดียว multi-modal model ตัวแรกออก summer 2026

**Google Antigravity 2.0** (19 พ.ค. + on-demand 21 พ.ค.) คือ signal ที่ Google ตัดสินใจ commit เต็มตัวกับ agent paradigm — replace Gemini CLI ทิ้งทั้งหมดด้วย agy CLI ใหม่ (Go-based) + desktop IDE + SDK + Managed Agents API tier + Gemini Enterprise Agent Platform ขับด้วย Gemini 3.5 Flash ที่เคลม outperform Gemini 3.1 Pro 4 เท่า UX หลักคือ subagent orchestration ที่ lead agent delegate ไป specialist subagent หลายตัว parallel — pattern เดียวกับ Claude Code/Codex/Cursor Composer Google ยังปล่อย Gemini Spark personal agent 24/7 ผูก Workspace + Gmail — "agents not chatbots" thesis ชัดเจน

**Nvidia + GPT-5.5 Codex deployment** (21 พ.ค.) เป็น proof point ที่ใหญ่ที่สุดของ company-wide agentic tool rollout — 10,000 พนักงาน ครอบคลุมทุก function (engineering, legal, marketing, finance, sales, HR, operations) รันบน GB200 NVL72 cluster 100,000 GPU เคลม 35x lower cost/token, 50x token output/sec/MW เทียบกับ generation ก่อน Internal report: debugging cycle "days → hours", non-engineer ship feature end-to-end จาก prompt ได้ — ใหญ่กว่า PwC + Anthropic Claude 30K user ที่กระจายหลายปี

Pattern หลักประจำรอบ — **agentic AI stack กำลัง mature ใน 3 layer พร้อมกัน: protocol (MCP), device/compute (Hark + GB200), และ developer experience (Antigravity + Codex)**. ทั้ง 3 ชั้นเชื่อมกัน — โดยที่ MCP จะกลายเป็น contract กลางระหว่าง agent framework กับ tool layer, GB200 เป็น compute backbone ที่ทำให้ inference cost ต่ำพอที่ company-wide rollout เป็นไปได้, Antigravity/Codex เป็น developer surface ที่ฝังเข้า workflow แต่ละองค์กร ผู้ชนะของรอบนี้คือ **บริษัทที่อยู่ใน 3 layer หรือ partner กับทั้ง 3 ก่อนคู่แข่ง**

## TL;DR สำหรับ Yoh

- **MCP 2026-07-28 RC คือ inflection point ของ MCP จาก dev protocol สู่ enterprise infrastructure layer** — stateless core หมายความว่า MCP server วิ่งหลัง plain HTTP load balancer ได้ทันที ลด ops cost ของ enterprise ลง significantly + OAuth 2.1 alignment ทำให้เข้า Okta/Auth0/Entra stack ที่ลูกค้ามีอยู่แล้ว 10 สัปดาห์ก่อน publish 28 ก.ค. คือ window ที่ทุก vendor ที่ขาย MCP server ต้องตัดสินใจ design choice ที่จะ ship — OpenBridge ถ้ามี MCP integration ใน roadmap ต้อง commit stateless model ตั้งแต่วันแรก

- **Hark $700M / $6B + chip vendor coalition คือ signal ที่เงินทุน AI-native hardware เปิดประตู** — ภายใน 18 เดือนเราเห็น Sierra (B2B agent), Hark (consumer device), Cursor, Replit Agent ขึ้นเป็น unicorn ทุกตัวมีจุดร่วมว่าผู้ใช้ไม่ต้องคิดว่ากำลังคุยกับ AI การที่ Nvidia+AMD+Intel+Qualcomm ลงทุนรอบเดียวกันคือ signal ที่ทุกค่ายเชื่อว่า Hark จะ ship hardware ที่ใช้ silicon ของทุกค่ายในรูปแบบใดรูปแบบหนึ่ง สำหรับ OpenBridge — คำถามที่ต้องคิดคือ "B2B AI-native experience จะหน้าตายังไงในปี 2027?" ก่อนคู่แข่งกระชาก narrative

- **Google Antigravity 2.0 + Spark = agent-IDE war เริ่มเต็มตัว** — Google ยอม disrupt user base ของ Gemini CLI ทิ้งเพื่อ commit เต็มตัวกับ agent paradigm; Spark ที่ผูก Workspace + Gmail แบบ deep integration เป็น **ความเสี่ยงตรง** สำหรับ workflow automation ระดับ SMB ที่ใช้ Google ecosystem (พื้นที่เดิมของ Zapier/Make/n8n); แต่ Spark อ่อนที่ cross-vendor — OpenBridge ที่ position ตัวเองเป็น "agent-ready integration layer ระหว่างหลายระบบ" จะมี window ถ้า ship MCP support เร็วพอให้ Antigravity SDK เรียก OpenBridge เป็น tool ได้

- **Nvidia + Codex 10,000 user คือ proof point ที่ใหญ่ที่สุดของ company-wide rollout** — pattern กำลังเปลี่ยนจาก "department by department" เป็น "company-wide AI deployment ทั้ง stack" เร็วกว่าที่ใครคาด ระวัง vendor claim 35x cost reduction เพราะ Nvidia+OpenAI เป็น partner ปาก vendor เดียวกัน + Nvidia เป็น lighthouse customer ที่ scale ไม่ได้เลียนแบบโดยตรง สำหรับ OpenBridge — buyer ใหญ่กำลัง expect "company-wide AI deployment + cross-tool orchestration" pitch แบบ "เริ่มจาก team เล็ก ๆ" ไม่ใช่ playbook ที่ดีที่สุดอีกต่อไป

- **Pattern หลักของ 4 ข่าวรวมกัน — agentic AI stack mature ใน 3 layer พร้อมกัน: protocol (MCP), compute/device (Hark + GB200), developer surface (Antigravity + Codex)**. ผู้ชนะรอบนี้ = บริษัทที่อยู่ใน 3 layer หรือ partner กับทั้ง 3 ก่อนคู่แข่ง MCP เป็น contract กลางระหว่าง agent framework กับ tool — OpenBridge ที่ขาย integration layer ควรเลือก position เป็น "MCP-native tool provider ที่ Tier-1 agent framework เรียกใช้ได้ทันที"
