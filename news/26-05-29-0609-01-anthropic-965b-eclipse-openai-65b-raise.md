# Anthropic ปิดดีล $65B จริงแล้ว — valuation $965B แซง OpenAI ครั้งแรกในประวัติศาสตร์ ARR พุ่งเป็น $47B ภายในเดือนเดียว

## TL;DR
- 28 พ.ค. Anthropic ประกาศปิด Series H มูลค่า $65 billion ที่ valuation $965B — แซง OpenAI ($852B จาก มี.ค.) เป็นครั้งแรก
- รอบนี้นำโดย Altimeter, Dragoneer, Greenoaks, Sequoia + Coatue/ICONIQ co-lead รวม Amazon ลงทุน $5B (ส่วนหนึ่งของ $25B commitment)
- ARR ทะลุ $47B (จาก $30B ที่รายงานเมื่อ เม.ย.) — ขึ้น $17B ภายในเดือนเดียว, Claude Code ยังเป็น engine หลัก

## เกิดอะไรขึ้น

วันที่ 28 พ.ค. 2026 Anthropic ประกาศปิด Series H อย่างเป็นทางการ — $65 billion ที่ post-money valuation $965 billion ตัวเลขนี้สำคัญเพราะมันคือครั้งแรกในประวัติศาสตร์ที่ Anthropic แซง OpenAI ในด้าน valuation OpenAI ปิดรอบล่าสุดที่ $852B เมื่อมีนาคม ส่วน Anthropic เพิ่งอยู่ที่ $380B เมื่อ Series G ในกุมภาพันธ์ — เพิ่มขึ้น 2.5 เท่าภายใน 3 เดือน

รอบนี้นำโดย Altimeter Capital, Dragoneer, Greenoaks Capital และ Sequoia Capital ร่วมกับ Coatue และ ICONIQ ที่เป็น co-lead จุดน่าสนใจคือ $15B จาก $65B เป็นการ commit เดิมจาก hyperscaler — รวมถึง $5B จาก Amazon ซึ่งเป็นส่วนหนึ่งของ commitment $25B ที่ Amazon ประกาศไว้เมื่อเมษายน

สิ่งที่ทำให้นักลงทุนกล้าจ่าย $965B คือตัวเลข ARR ที่ Anthropic เปิดเผยพร้อมประกาศ — run-rate revenue ข้าม $47 billion ในช่วงต้นเดือนพฤษภาคม เทียบกับ $30B ที่ Dario Amodei เปิดเผยเมื่อเมษายน หมายความว่า Anthropic เพิ่ม ARR ได้ $17B ภายในเวลาแค่เดือนเดียว enterprise adoption เร่งตัวขึ้นทั้ง global

ในบริบทที่กว้างขึ้น สัปดาห์เดียวกันยังมีข่าวใหญ่อื่น ๆ — Cognition ปิดรอบ $1B ที่ $26B (รายงานเมื่อ 27 พ.ค.), Robinhood เปิด agentic trading ผ่าน MCP (27 พ.ค.), Fujitsu ลงทุนใหญ่กับ Anthropic + OpenAI สำหรับตลาดญี่ปุ่น (27 พ.ค.) — ทั้งหมดบ่งชี้ว่าเงินใน AI ecosystem ไหลแรงขึ้นพร้อมกันในระดับ unprecedented

## ทำไมสำคัญ

ตัวเลขที่ทำลายสถิติคือ ARR ที่กระโดด $17B ในเดือนเดียว — ถ้าจริง นี่คือ growth rate ที่ไม่เคยมีบริษัทไหนในประวัติศาสตร์ทำได้ในระดับ revenue $30B+ Salesforce ใช้เวลา 20 ปีกว่าจะถึง ARR ระดับนี้, Microsoft Azure ก็ใช้เวลาเป็นทศวรรษ — Anthropic ทำสิ่งเดียวกันภายใน 3 ปี และการเพิ่ม $17B/เดือนหมายความว่า monthly revenue growth ของ Anthropic ตอนนี้น่าจะเทียบเท่า annual revenue ของ unicorn ขนาดกลางทั้งบริษัท

อีกประเด็นที่ underrated คือ Amazon investment — $5B รอบนี้, รวมแล้วใกล้แตะ $25B commitment ของบริษัทเดียวที่ทุ่มลงไปใน startup เดียว ก่อนหน้านี้แค่ Microsoft กับ OpenAI ที่ทำได้ในระดับนี้ ตอนนี้ Amazon vs Anthropic ก็คงคู่นั้นเช่นกัน — และ Anthropic ใช้ Trainium chips ของ AWS เป็นหลักไม่ใช่ NVIDIA หมายความว่า Anthropic จะกลายเป็น case study ที่ใหญ่ที่สุดของ AWS Trainium chip economics ในอีก 12 เดือนข้างหน้า

Pattern ที่เห็นชัดในไตรมาสนี้คือ **valuation convergence ที่ระดับ ~$1T** — OpenAI, Anthropic ทั้งคู่กำลังจะแตะ trillion-dollar club ก่อน IPO ตัวเลขนี้สะท้อนว่า public market กำลังจะมี AI mega-cap ใหม่ 2 ตัวพร้อม ๆ กัน ซึ่งจะ reshape index weightings และ AI sector valuation ทั่วทั้งตลาด

## มุม OpenBridge

สำหรับ OpenBridge สิ่งที่ต้อง take away คือ **ARR $47B ไม่ใช่ตัวเลขที่บริษัท ขาย model อย่างเดียวจะสร้างได้** — มันต้องมาจาก mix ของ Claude API + Claude Code + enterprise managed agents + ecosystem integrations ที่ทำงานครบวงจร Anthropic ไม่ได้ขายแค่ AI แล้ว — ขาย "AI ที่ทำงานในระบบ enterprise จริง" ซึ่งหมายความว่า integration layer ที่เชื่อม Claude เข้ากับ enterprise toolchain คือเลเยอร์ที่ Anthropic ต้องการ partner ไม่ใช่แข่ง

อีกมุม — Anthropic ที่ valuation $965B จะมี capital ขนาดมหึมาที่จะลงทุนใน ecosystem players ตอนนี้ Series H นี้ปิดแล้ว Anthropic Venture Arm น่าจะเริ่ม active กว่าเดิม (เรามี Anthropic + Glasswing + Mythos ลงทุน security agent ไปแล้วเมื่อสัปดาห์ก่อน) OpenBridge ที่ position ตัวเองเป็น MCP-native integration backbone อาจเป็นเป้าหมาย investment ที่ Anthropic เห็นค่าได้ — โดยเฉพาะถ้าเราเป็น neutral layer ที่รองรับทั้ง Claude และ competitor
