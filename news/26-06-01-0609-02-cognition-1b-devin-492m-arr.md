# Cognition ระดม $1B ที่ valuation $26B — Devin ทำ ARR $492M, AI เขียนโค้ดตัวเอง 90%

## TL;DR
- **Cognition (Devin) ปิด $1B funding รอบใหม่ที่ valuation $26B** (27 พ.ค.) — เพิ่ม 2.5 เท่าจาก $10.2B เมื่อ 8 เดือนก่อน
- **ARR ตอนนี้อยู่ที่ $492 ล้าน** — enterprise usage โต 50% MoM ติดต่อกัน 6 เดือน
- **90% ของ codebase Cognition เองเขียนโดย Devin** — proof point ที่ founder Scott Wu บอกว่า "AI ไม่ได้แทน engineer, มันให้ engineer ทำงานในระดับที่สูงขึ้น"
- Customer list: **Mercedes-Benz, NASA, Goldman Sachs, Santander** — ลูกค้าที่ใช้ regulated workflow ทั้งหมด
- รอบนี้นำโดย **Lux Capital, General Catalyst, 8VC**; Founders Fund, Ribbit, Atreides, Layer Global เข้ามาเพิ่ม

## เกิดอะไรขึ้น

วันที่ 27 พฤษภาคม Cognition AI — บริษัทที่อยู่เบื้องหลัง **Devin** ซึ่ง market ตัวเองว่าเป็น "first AI software engineer" — ประกาศปิด funding round ใหม่ที่ระดม **$1 พันล้าน** ที่ valuation **$26 พันล้าน** post-money ($25B pre-money). นำโดย Lux Capital, General Catalyst และ 8VC; existing investor Elad Gil, Soma Capital, Omri Casspi, Founders Fund ตามด้วย new investor Ribbit Capital, Atreides Management, Layer Global

ที่ทำให้ valuation นี้ defendable ไม่ใช่ hype แต่เป็นตัวเลข business: **annualized revenue run-rate $492 ล้าน** + **enterprise usage โต 50% เดือนต่อเดือนติดต่อกัน 6 เดือน**. คำนวณ trajectory แบบ conservative ตอน end of 2026 จะอยู่ที่ ~$1.5B ARR — แปลว่า Cognition ทำเวลาจาก zero ไป $1B ARR ใน ~24 เดือน, **เร็วกว่า Salesforce, Snowflake, Datadog** ทั้งหมด

จุดที่ founder Scott Wu ใช้เป็น signature talking point คือ **"90%+ ของ codebase ภายในของ Cognition เขียนโดย Devin"** — แต่ใน press round Wu ขยายความว่า "AI ไม่ได้แทน engineer, มันให้ engineer ของเราทำงานในระดับที่สูงขึ้น" — เป็น narrative ที่ designed มาให้ดู rebuttable กับ critique เรื่อง white-collar layoff, แต่ตัวเลข engineer headcount ที่ Cognition ไม่ peep ใน press release

Customer base ที่เปิดเผยในรอบนี้ทำให้ทุกคนสะอึก: **Mercedes-Benz** (manufacturing systems integration), **NASA** (mission-critical software), **Goldman Sachs** (trading system development), **Santander** (core banking modernization). สี่บริษัทนี้ตัวแทน 4 อุตสาหกรรมที่ regulator จับตามากที่สุด — แปลว่า Devin ผ่าน internal security review ของหน่วยงานเหล่านี้แล้ว ไม่ใช่ pilot กับ side project

## ทำไมสำคัญ

เรื่องนี้ confirm ว่า **agentic coding ผ่าน proof-of-economics**. ปีที่แล้วยังเป็นคำถามว่า "AI agent เขียน production code ได้จริงหรือเปล่า" — ปีนี้คำถามเปลี่ยนเป็น "ค่าใช้จ่ายต่อ task คุ้มหรือเปล่า" — และ Cognition ตอบด้วย ARR ที่โต 50% MoM กับลูกค้าที่ regulated ที่สุดในโลก. ในวงการ enterprise software นี่คือ moment ที่เคยเรียกว่า "category formation complete"

ที่น่าสังเกตคือ **valuation multiple ของ Cognition อยู่ที่ ~53x ARR** — สูงกว่า Anthropic (20x), OpenAI (~30-40x) เกือบสองเท่า. นักลงทุนยอมจ่าย premium เพราะ Cognition operates **layer ที่สูงกว่า model** — เขาเป็น "operating system สำหรับ engineering team" ไม่ใช่ model provider. ถ้า moat ของ application layer แข็งจริง (workflow data, integration, retention) — multiple นี้สมเหตุสมผล; ถ้าไม่ — รอบหน้าจะเป็น down round

Pattern ที่ฉายชัด: **2025 = funding rounds ใหญ่ที่สุดอยู่ที่ model labs (OpenAI, Anthropic); 2026 = funding ใหญ่ที่สุดอยู่ที่ application layer ที่ vertical** (Cognition coding, Harvey legal, Sierra customer support). ทุน venture เริ่มเชื่อแล้วว่า application layer มี durable moat ไม่ใช่แค่ thin wrapper บน GPT/Claude. Wu บอกว่า "AI ไม่แทน engineer, ให้ engineer ทำงานสูงขึ้น" — แต่ realistically, **ทีม 10 engineer + Devin = ผลผลิตของทีม 50 engineer**, และนั่นคือ reason ที่ revenue โตเป็น compound 50% MoM. ลูกค้าไม่ได้ซื้อ "productivity tool" — ลูกค้าซื้อ **headcount substitute**

อีก subplot ที่น่าจับตา: Devin "90% ของ codebase เขียนเอง" — เป็น narrative ที่บริษัทอื่น (Anthropic บอก ~90% ของ code Claude Code project เขียนโดย Claude, Cursor บอก similar) เริ่มใช้เป็น flex. ภายในสิ้นปี 2026 standard ของ AI-native company จะกลายเป็น "AI เขียน code ของตัวเอง 80%+" — และนั่นจะเปลี่ยน economics ของ Series A startup ทั้งหมด: ทีม 5 คน raise $5M ทำสิ่งที่เคยต้องการ 30 คน $30M

## มุม OpenBridge

**Devin ราคาแพง — Cognition charge enterprise rate.** ตลาด SMB ไทยไม่มี budget. นี่คือ wedge ของ OpenBridge: **wrap Devin หรือ open-source equivalent (SWE-agent, Aider, Devstral) ในชั้น team management + Thai-language workflow + per-seat pricing** ที่ SMB จ่ายไหว (เริ่ม $50/dev/month แทนที่จะเป็น $500). ใช้ pattern เดียวกับ Cognition แต่ target ตรงข้าม

**Internal play ที่ทำได้ทันที**: ถ้า OpenBridge ยังไม่ได้ measure ว่า codebase ภายใน % เขียนโดย AI agent — เริ่มวันนี้. ตัวเลขนี้กำลังจะกลายเป็น **due diligence metric** สำหรับ Series A ปี 2027. นักลงทุนจะถาม "AI velocity ratio ของทีมคุณคือเท่าไหร่" เหมือนถาม burn rate. Cognition + Anthropic + Cursor ตั้ง bar ไว้ที่ 80-90% — ทีม OpenBridge ควร benchmark ทุก sprint

**Customer signal**: Mercedes/NASA/Goldman/Santander = 4 รัฐ regulated. แปลว่า compliance/audit ผ่านได้แล้ว — ปลดล็อก SMB ไทยใน finance + healthcare ที่ยังกลัว AI coding tool. OpenBridge ใช้ logo เหล่านี้เป็น proof point ใน sales deck ได้ ("คล้ายกับ stack ที่ Goldman Sachs ใช้") — กฎเดียวคือต้องเขียน "powered by" architecture เปิดเผยตามเดิม ไม่ใช่ claim ว่าเป็น OpenBridge IP
